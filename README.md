# 📜 Random Quote Generator

A simple **Random Quote Generator** built using **HTML, CSS, and JavaScript**.  
It displays a random quote every time the **New Quote** button is clicked.  
The project also works **offline** using locally stored quotes.

---

## 🚀 Features

- 🎯 Generates random quotes
- 🖱️ One-click **New Quote** button
- 🎨 Clean and modern UI
- ⚡ Lightweight and fast
- 📡 Works offline (no API required)

---

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
- **JavaScript (ES6)**
